## 书写基线（规范自然的书面表达）

本节管措辞与句法，对下文各张文体卡都生效。文体卡决定内容组织、读者适配和示例范围，本节管句子怎么写；两处出现实质冲突时，按任务用途和材料判断，并在交付中说明取舍。

**基本要求**

写规范、自然的书面表达。指代落到具体对象，条件和动作的衔接交代清楚，必要的复句保留，句子的长短和标点服从信息之间的关系。中性书面词照常使用，口语词不出现，「塞进」「拿走」「干等着」「跟前」「跑一趟」「闲着也是闲着」这类写法都避开；表示必须的情态「得」加动词同样不写，「得提前约好」「得自己写」属于此类，作结构助词的「得」不在禁用范围，「跑得快」「写得好」照常写。

把字句、数量叠词（「一张一张」「一行一行」）和分号按内容取用，不要求每段都出现。比较的强度不超过材料给出的程度，材料说「略慢」就写「略慢」，不统一升格成「慢得多」。术语按上下文和读者固定使用，技术缩写直接用，「CPU」不展开，主机、磁带、读卡器、打印机也不换成别的叫法；不把「主机」一律改成 CPU，也不为称呼统一把 CPU 改回「主机」。单一维度的比较表和教学中的数值算例都可以保留，表格去留看读者的任务，不看表的形状和数量。

**偏好记录**

下面几条各自独立，分开使用，不拼成一段范文。

- 「一个作业跑完，监控程序从队列里取下一个接着跑」，改为「每跑完一个作业，监控程序就从队列里取下一个继续运行」。原记录写作「取下下一个」，属于重复字的笔误，两侧统一改为「取下一个」。这一条可学的是条件和动作的衔接，不要求其他句子一律以条件从句开头。
- 「读卡器一张一张读卡片，打印机一行一行出结果，都比主机慢」，改为「读卡器一张一张读卡片，打印机一行一行出结果，读卡器和打印机都比CPU要慢得多」。这是这处材料的指定写法；其他材料里的「略慢」不升格成「慢得多」，主机和 CPU 也不当作可以随意互换的同义词。
- 「把这两件事挪到主机外面的专用设备上」改为「把读卡和打印放到主机外面的专用设备上」；「主机只管跟磁带打交道」改为「主机负责计算」。可学的是指代明确、直接说明工作，不据此判断原句的历史事实正误。该条的原始记录写作「方到」，按「放到」的笔误修正。
- 偏好方向是「主机只管跟磁带打交道」改成「主机负责计算」，记录时不要把两边颠倒。

**不采用的写法与采用的写法**

|不采用|采用|
|---|---|
|一个作业跑完，监控程序从队列里取下一个接着跑|每跑完一个作业，监控程序就从队列里取下一个继续运行|
|读卡器一张一张读卡片，打印机一行一行出结果，都比主机慢|读卡器一张一张读卡片，打印机一行一行出结果，读卡器和打印机都比CPU要慢得多|
|把这两件事挪到主机外面的专用设备上|把读卡和打印放到主机外面的专用设备上|
|主机只管跟磁带打交道（用作收口句）|主机负责计算|

第二行的「慢得多」只对这一处材料有效，不作为通用的比较强度；第一行两侧原写作「取下下一个」，按重复字的笔误改成「取下一个」，第三行原记录的「方到」按「放到」改正。

**样句的用法**

「每跑完一个作业，监控程序就从队列里取下一个继续运行」只示范条件和动作的衔接，不作为通用句式模板，其他句子怎么写服从各自的信息关系。

**例外**

标题、按钮、标签这类短文案按各自的格式约束压缩，不套用正文的展开方式。日常沟通保留称呼和需要对方做的动作。用户逐任务指定了风格、术语或篇幅的，按用户的写法执行。

## 技术说明

**读者与用途** 面向需要了解对象如何工作、在什么条件下工作的开发者和使用方，交付可以据以操作或判断的说明。

**措辞** 通行术语和具体动词，必要复句保留，不为正式而替换为生僻词。

**句法** 条件、时机和结果的衔接交代清楚，限定信息不被拆散。

**段落推进** 围绕对象、行为、条件和代价展开，只写材料支持的机制和结论。

**叙述语气** 判断跟着材料走，材料给出多少就说到多少。

**修改边界** 已有文字只改病句、含混和与硬性禁令冲突的地方，保留原文的术语和操作顺序，不为贴合本卡统一改写句式。

**参照样文** 作者阮一峰，作品《ES6 入门教程》，来源 https://wangdoc.com/es6/let ，章节「let 命令 / 基本用法」，取段自「ES6 新增了`let`命令，用来声明变量」起，到「这表明，`let`声明的变量只在它所在的代码块有效。」止，包含 `let a = 10` / `var b = 1` 代码块和块外访问的结果。

**可学的写法**

- 直接交代行为和它的适用范围
- 动词具体，落在对象的动作上
- 有示例时说明真正改变结果的那个差别

**不模仿的写法**

- 反复出现的「上面代码」「这表明」这类衔接脚手架
- 固定的段落骨架
