Current marketplace scope is limited to `omp-config`, `writing-helper`, and
`omp-fact-checker`. The workflow catalog contains `writing`, `research`, and
`visual` domains. Code-enhancement core, testing-enhancer, ECC coding skills,
and their runtime guidance are not part of the current installation.

All workflow cards are advisory. Main orchestrates through ANALYZE -> EXECUTE
-> REVIEW; Skills, Agents, permissions, external effects, and completion remain
owned by OMP and the acting Main. The index exposes exact top-level Skill URIs
as optional candidates and does not create a router or gate.
